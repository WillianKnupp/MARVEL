# MARVEL — Catálogo de Personagens

Projeto web desenvolvido para apresentar personagens do universo Marvel em um catálogo interativo, permitindo explorar heróis e vilões, visualizar informações e organizar personagens favoritos.

## Sobre o projeto

O MARVEL é uma aplicação desenvolvida com HTML, CSS e JavaScript, com foco na criação de uma interface visual e interativa.

Ao selecionar um personagem, o usuário pode visualizar informações adicionais, incluindo sua descrição e principais habilidades.

## Funcionalidades

- **Catálogo de personagens:** visualização dos personagens do universo Marvel.
- **Busca inteligente:** pesquisa por nome ou identidade do personagem.
- **Ordenação:** organização alfabética de A–Z ou Z–A.
- **Sistema de favoritos:** possibilidade de adicionar e remover personagens dos favoritos.
- **Armazenamento local:** favoritos salvos utilizando LocalStorage.
- **Detalhes dos personagens:** exibição de descrição e habilidades em uma janela interativa.
- **Filtros:** visualização exclusiva dos personagens favoritos e opção para limpar os filtros.

## Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e organização visual.
- JavaScript — funcionalidades, interatividade e manipulação do DOM.
- LocalStorage — armazenamento dos personagens favoritos no navegador.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão local.

## Objetivo do projeto

Este projeto foi desenvolvido como prática de desenvolvimento web, com o objetivo de aprimorar conhecimentos em HTML, CSS e JavaScript, especialmente na manipulação do DOM, gerenciamento de eventos, filtros, organização de dados e armazenamento local.
